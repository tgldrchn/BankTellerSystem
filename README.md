# Банкны Теллерийн Систем

Энэ бол багийн төсөл юм. Банкны үндсэн үйл ажиллагааг дижитал болгосон систем.

## Юу хийдэг вэ?
- Үйлчлүүлэгчид хүлээлгийн дугаар олгоно
- Теллер гүйлгээ хийнэ
- Валютын ханшийг бодит цаг хугацаанд харуулна

## Архитектур

Бүх клиент апп **WebAPI**-гаар л харилцана. Шууд хоорондоо холбогддоггүй.
Ханш өөрчлөгдөх, дугаар дуудагдах үед **SignalR** бусад дэлгэцүүдийг шууд мэдэгдэнэ.

- Дугаар терминал → WebAPI → SQLite
- Теллерийн апп → WebAPI → SQLite
- Blazor дэлгэц ← SignalR (бодит цагийн мэдэгдэл)

## Технологи
- **ASP.NET Core** — сервер
- **SignalR** — бодит цагийн мэдэгдэл
- **WinForms** — дугаар терминал, теллерийн апп
- **Blazor** — валютын дэлгэц
- **SQLite** — өгөгдлийн сан
- **System.Threading.Channels** — гүйлгээний дараалал
